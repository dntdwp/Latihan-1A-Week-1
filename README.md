# Java Fundamentals — Week 1

Introductory Java exercises: variables, data types, operators, type casting, and the Math API.
Coursework: Teknik Pemrograman, JTK Politeknik Negeri Bandung.

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)

## 📁 Files
| File | Topic |
| ---- | ----- |
| `Variables1.java` / `Variables2.java` | Variables, `final` constants |
| `DataTypes.java` | Primitive type ranges (`byte`–`long`), try-catch input |
| `Operator.java` | Pre/post increment, short-circuit `&&` |
| `Type_Casting.java` | Widening/narrowing casts (`double`→`float`→`long`→`int`→`short`→`byte`) |
| `Arithmetic_Math_Class.java` | `Math.round` |

## 🚀 How to Run
```bash
javac *.java
java DataTypes
java Operator
```

## 🎓 What I Learned
- Primitive type limits and safe narrowing casts
- Operator precedence and side effects (`++a`, `b++`)
- `final` constants vs mutable variables
